# Contenu de démonstration

Un petit pack (`demo`) et un scénario, inventés pour Taleweaver : rien n'est tiré de Middara. C'est le contenu de l'appli publiée par la CI, et celui de la e2e quand le contenu du jeu manque.

- `packs/demo/` : deux combattants, deux tuiles, deux jetons, un dé à six faces, une arme.
- `scenarios/demo/bandit-clearing.json` : une scène, une rencontre, une fin.
- `assets/demo/` : images dessinées par script.

Lancer l'API dessus : `Content__RootPath=demo` (chemin relatif au dossier de l'API : `../../demo`).
